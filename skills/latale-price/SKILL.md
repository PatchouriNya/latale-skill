韩服彩虹岛（라테일）物价分析 playbook：把交易行截图或粘贴数据变成可决策的行情结论，并沉淀到工作区历史库。

**快速录入模式**：用户只喂数据、没问分析问题时，只做 1–3 步（采集→归一化→沉淀），不做 4–5；最后用一两行确认"本次录入 N 条、新增映射 M 个"。

## Steps

### 1. 采集

- **截图**：读图逐条转写每一条上架记录——物品名（韩文原文）、单价、数量、强化等级、词条。转写要全，不概括、不挑重点。
- **粘贴**：把文本/表格解析成记录行；字段缺失按常识推断并在 note 标注；价格或物品名缺失的整条丢弃。

完成标准：每条记录都有 [日期、韩文名、价格]，缺一不算记录。

### 2. 归一化

- 查 [`items-kr-zh.md`](items-kr-zh.md) 得标准名；表里没有的名字，判定类别后把新条目追加进表（同一物品只保留一个标准名，优先常用叫法，不猜含义）。

完成标准：本次所有记录都已归一化，且新名字全部补进映射表——留一个未归一化名字就不算完成。

### 3. 沉淀

- 追加到 `<workspace>/data/latale-prices.csv`（不存在就带表头创建）。
- 历史行只增不改：修正以新行 + note 追加，绝不覆盖或删除旧行。
- 去重：date + item + price + enhance + options 全同视为重复，跳过。

完成标准：CSV 行数 = 原行数 + 新增记录数。

### 4. 分析

- 按 [`analysis-framework.md`](analysis-framework.md) 逐维度分析用户问到的点。
- 数据不够（档内样本 < 3，或历史 < 2 个日期）时，明确说"数据不足"，给区间而不是结论。

完成标准：每个被问到的维度都有结论 + 依据数据行；数据不足的维度有显式标注。

### 5. 报告

- 输出：行情表（物品、价格、区间、样本量、日期）、结论列表（每条含依据与置信度）、数据不足项。
- 结论必须能追溯到具体记录行——不可追溯的结论不写。

完成标准：用户能直接拿报告做买卖/自制决策。
