# 彩虹岛装备体系（价值评估知识库）

用户提供的韩服装备系统权威规则。评估装备价值前先查本节。

## 强化等级（7 级，显示在装备名右侧）

顺序：`☆ → ☆☆ → ☆☆☆ → ★☆☆ → ★★☆ → ★★★（三黑）→ 超越`

- ☆ 为白星、★ 为黑星；**三个黑星 = 三黑**（★★★）
- 等级显示在**装备名称右侧**，不是下方的镶嵌/词条等级
- 词条可敲等级上限随强化等级提高：**白板装备词条最多敲到 lv2；到三黑可敲 lv5**

## 词条系统

- **白板装备**掉落时带 **4 个随机词条 lv1**（lv1 词条 = +1 点数值）
- 敲词条（强化词条等级）成功率，**失败装备直接炸掉**：
  | 白金锤数 | 成功率 |
  |---|---|
  | 1 个 | 50% |
  | 2 个 | 60% |
  | 30 个 | 100% |
- **lv1→lv2** 有上述成功率区分；**lv2→lv5 均 100% 成功**，但加的数值在范围内随机
- 每件装备还可**额外自选敲 1 个 lv2 的新词条**（非已有词条），成功率同上
- 一件装备**最多 5 个词条**（4 随机 + 1 自选）
- 白金锤市价见价格库（参考：1.5e/个 → 30 个 = 45e 保底）

## 觉醒（红色属性部分）

- 觉醒属性价值**完全看数值多少**，数值高低决定值不值钱
- 装备有"不可觉醒"与"可觉醒（+1次）"之分（封印状态相关）

## 价值评估模型

- `估值 = 白板价 + 强化加价 + 词条价值 + 觉醒价值`
- 强化加价按等级递进（示例：格伦薇尔靴子 超越 ≈ +400e）
- 词条价值看：等级（lv5 > lv2）、数值、百分比（如 84%/98%/100%）、是否极品词条
- 自制成本必须计入敲词条的失败率期望：`1 锤(50%) 期望成本 = 2×锤价`，失败还可能炸掉整件装备
